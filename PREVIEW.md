# Data Science Hub — SaaS Pro Preview

## Fastest
Open `index.html` directly in a modern browser.

## Local preview server
From this folder:

```bash
python3 preview-server.py
```

Then open `http://127.0.0.1:4173/#/`.

## Main routes
- `#/` — SaaS dashboard
- `#/lessons` — lesson library
- `#/paths` — learning paths
- `#/quiz` — quizzes
- `#/lab` — interactive playgrounds
- `#/projects` — guided projects
- `#/progress` — progress analytics
- `#/settings` — preferences

The app remains offline-first and does not require external CDNs.
